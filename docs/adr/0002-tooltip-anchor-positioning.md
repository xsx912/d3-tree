# 悬浮框定位从跟随光标改为锚定节点

悬浮框原跟随鼠标移动（mousemove 平移 + 边缘翻转）。改为**锚定节点**：出现在节点外侧（水平布局：左节点→左侧、右/根→右侧；垂直布局方向感知为上/下），缩放/平移时随节点重算。动因：内容组件化与异步数据落地后，跟随光标的浮层在加载期间会持续抖动、且与"单实例常驻"的心智不符——锚定让浮层稳定贴住语义主体（节点），光标在节点内移动不再引起位移。放弃的选项：follow/anchor 双模式可配（配置面与碰撞测试双倍，无真实需求）；继续跟随光标（与异步骨架屏组合体验差）。副作用：位置不再依赖鼠标坐标，翻转修正依赖内容尺寸（替换后一帧 rAF 自动补一次；异步变高由组件自管）。
