# d3-tree 双向树图谱（产业链图谱）实施方案 v2

## 需求基线（三份输入合成）

1. **视觉参考图**（vision-reader 已分析）：企业产业链图谱风格——根节点居中、左右横向展开；圆角矩形自适应宽度节点；根节点蓝底白字加大（约 #1E6EFF）、普通节点白底浅灰描边（#DCDFE6 / 文字 #303133）；**直角折线连线**（1px #C0C4CC）；节点外侧 **+/− 圆形徽标**；**“展开 (N)” 聚合节点**（懒加载分批展开）；纯白背景、克制配色；画布内无其他 UI
2. **官方 collapsible-tree 示例**（源码已核对）：`children ↔ _children` 置换切换；250ms 过渡；新节点从被点击节点旧位置长出、收起节点回拢到父节点新位置（`x0/y0` 记忆）；`d3.tree().nodeSize()`
3. **已确认决策**：pnpm monorepo（core/vue/react 三包 + demo）、功能全量（缩放平移、折叠展开、着色+tooltip+图例筛选、搜索高亮定位、导出 PNG/SVG、追加/删除节点）

## 核心 API

```ts
createBidirectionalTree(container, {
  data, duration: 250,
  visibleChildrenLimit: 5,        // 超出聚合为“展开 (N)”，点击分批展开
  linkStyle: 'orthogonal',        // 'diagonal' 可选
  rowHeight: 48, columnGap: 48,   // 列间距自适应节点宽度
  nodeColor?, tooltip?, onNodeClick/Toggle/Select...,
})
  .addChild(parentId, node)  .removeChild(id)
  .toggle(id)  .collapseAll()  .expandAll()
  .search(kw)  .clearSearch()    // 高亮+祖先链，定位首个命中
  .setVisibleGroups(gs)          // 图例筛选
  .exportImage({format:'png'|'svg', scale})  .zoomToFit()  .destroy()
```

交互约定：**点击节点或 +/− 徽标 = 折叠/展开**（对齐官方示例）；悬停 = tooltip；demo 中“追加子节点”走工具栏选取父节点的流程，避免与折叠冲突。

## 布局算法（变宽节点 + 列对齐）

1. canvas measureText 度量每个节点自适应宽度（根节点 16px 粗体单独算）
2. 根的子节点按 `side`（缺省均分）拆左右两侧，各建 `d3.hierarchy`
3. 每侧跑 `d3.tree().nodeSize([rowHeight, 1])` 取纵向排序坐标
4. 横向坐标按深度分列：`x[depth] = x[depth-1] + 该列最大宽度 + columnGap`（还原参考图“子列严格对齐”）；左侧取负镜像，两根对齐 (0,0)
5. 连线：正交折线 generator（父边 → 公共竖线 → 子边），可选 `d3.linkHorizontal`
6. 折叠/展开：官方 `children/_children` 模式 + d3.join 过渡；+ 徽标显示被折叠后代数
7. 聚合：每节点默认渲染前 5 个子节点 + “展开 (N)” 虚拟节点，点击释放下一批，取尽后消失；留 `loadChildren` 异步回调缝（将来接 API）

## Vue / React 封装与 demo

薄封装组件（props → chart 方法，ref 暴露命令式 API）。demo 三页共用工具栏（图外 UI）：搜索框、追加节点表单、全展开/折叠、导出、图例芯片、适配视窗；示例数据按参考图造一份**产业链风格中文数据**（企业 → 左右产业板块 → 细分，含折叠态）。
