# 02: 折叠展开（官方 collapsible-tree 模式）

**What to build:** 点击节点本体或其外侧 +/− 圆形徽标，子树折叠/展开，行为与动画对齐 d3 官方 collapsible-tree 示例：`children/_children` 置换、250ms 过渡、新节点从被点击节点旧位置长出、收起时回拢到父节点新位置（x0/y0 记忆）。徽标随状态显示 + 或 −，左半区徽标在节点左侧、右半区在右侧；徽标悬停 title 提示被收起的后代数量。提供 `toggle(id)` 程序化接口与 `onNodeToggle` 事件。

**Blocked by:** 01（脚手架 + 静态双向树最小闭环）

**Status:** ready-for-agent

- [ ] 点击节点本体触发折叠切换；再次点击展开，位置/过渡正确
- [ ] 点击 +/− 徽标与点击节点本体行为等价
- [ ] 徽标符号随折叠态切换（折叠时 +，展开时 −），位置符合左右半区规则
- [ ] 展开的子节点从被点击节点处长出；收起时子节点回拢到父节点（视觉验证）
- [ ] 数据带 `collapsed: true` 的节点初始为折叠态
- [ ] `toggle(id)` 程序化切换可用；`onNodeToggle` 回调携带节点与新的折叠态
- [ ] jsdom 测试：点击后 DOM 节点数随折叠增减、徽标类名切换、toggle API 生效
