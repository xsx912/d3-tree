## 行为决策

- 每次 setData 调用建立新数据代次，包括重复传入同一对象。旧异步响应不得改写数据、折叠/释放/loading 状态或调用错误、切换事件。
- setData 清除搜索及已有 DOM 的搜索类；保留现有缩放行为，折叠/释放/分组状态维持目前的重置规则。
- 用户 ID 仍用于公共命令与回调；渲染 key 与虚拟节点身份独立，不要求调用端避开某个字符串前缀。
- React 悬停回调函数身份变化不重建；是否启用自接管模式的变化可以重建。toggleOnNodeClick 热更新。其余配置函数不统一改为晚绑定，保留各自配置语义。
- React 兼容目标采用当前实际声明的 18/19；文档工单消除旧规格中 17 的矛盾，不引入 React 17 兼容实现。
- 开发环境与库消费环境分开表述；Vite 7 的最低版本约束不自动等同于发布库运行时约束。
- 不新增默认 HTML 转义行为，不在缺乏基准时拆分 chart.ts 或实施性能优化。
